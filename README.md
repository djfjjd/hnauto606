# 하나오토 주차 관리 대시보드

하나오토 606호 중고차 매매 현장에서 차량 위치, 빈 자리, 점검 상태와 서비스 작업 위치를 빠르게 확인하고 처리하는 반응형 웹 앱입니다.

> **데모 안내:** 현재 버전은 실제 운영 데이터베이스와 연결되지 않습니다. 모든 변경은 해당 기기의 브라우저 `localStorage`에만 저장되며 다른 직원과 공유되지 않습니다.

## 제공 기능

- 전체 주차면·주차 차량·빈 자리·확인 필요 차량 통계
- 일반 주차 및 광택·판금·수리 서비스 구역별 배치
- 차량번호·차종·색상 검색과 구역·상태 필터
- 배터리, 주유, 키 방전, 엔진 경고등, 공기압, 요소수 상태 표시
- 차량 상세 조회, 신규 입차, 정보 수정, 빈 자리 이동, 출차 처리
- 데스크톱·태블릿·390px급 모바일 반응형 UI
- 메뉴와 조작 버튼을 제외한 인쇄용 주차 현황
- 저장 데이터 손상 및 빈 검색 결과 안내

## 설치 및 실행

Node.js 20 이상(LTS 권장)과 npm이 필요합니다.

```bash
npm install
npm run dev
```

개발 주소는 기본적으로 `http://localhost:5173`입니다.

```bash
npm run build
npm run preview
```

빌드 결과는 `dist/`에 생성됩니다. 별도 테스트·린트 스크립트는 현재 없으며, 배포 전 `npm run build`, `git status`, `git diff --check`를 실행합니다.

## 데이터와 보안

운영 전 기존 데이터베이스 구조와 백업을 먼저 확인해야 하며 운영 데이터를 임의로 삭제하거나 변경하면 안 됩니다. 비밀번호, API 키, 토큰은 저장소에 커밋하지 않습니다. 필요한 변수 이름은 `.env.example`에만 기록하고 실제 값은 배포 환경에서 관리합니다.

여러 직원이 데이터를 공유하는 최종 구조는 다음 중 하나를 권장합니다.

1. 기존 Supabase가 운영 중이면 유지: 기존 인증·정책·백업을 보존하며 점진적으로 화면만 교체하기 좋습니다.
2. 기존 백엔드가 없고 Cloudflare 중심으로 운영한다면 D1로 이전: Pages/Workers와 통합이 단순하고 배포 구성을 한곳에서 관리하기 좋습니다.

두 방식 모두 `vehicles`, `parking_spots`, `vehicle_statuses`, `service_history`, `users/roles`, `audit_logs`를 분리하고 서버에서 권한 검증과 변경 이력을 기록해야 합니다. 현재의 `localStorage` 데이터는 운영 원본으로 사용하지 않습니다.

## Cloudflare Pages 배포

- 프로덕션 브랜치: `main`
- 빌드 명령: `npm run build`
- 출력 폴더: `dist`
- Node.js: 20 또는 22 LTS

`public/_redirects`가 SPA 새로고침을 `index.html`로 연결합니다. 환경 변수의 실제 값은 Cloudflare 대시보드의 Pages 프로젝트 설정에 등록합니다.

GitHub에 푸시한 뒤 Cloudflare **Workers & Pages → Create → Pages → Connect to Git**에서 저장소를 연결합니다. 도메인이 확정되면 **Custom domains**에서 대표 도메인을 추가하고 DNS 레코드, HTTPS 인증서 활성화, `www` 사용 여부와 대표 도메인 리디렉션을 확인합니다.

## 운영 전 체크리스트

- 현행 데이터 백업 및 차량·주차면 필드 매핑
- 직원 로그인, 역할별 권한, 변경 이력, 자동 백업 정책 확정
- 실제 주차면 수·이름·서비스 구역과 데모 구성이 일치하는지 대조
- 스테이징에서 검색, 입차, 수정, 이동, 출차, 인쇄 및 모바일 검증
- 최종 데이터 이전 중 입력 중지 시간과 롤백 절차 확정
